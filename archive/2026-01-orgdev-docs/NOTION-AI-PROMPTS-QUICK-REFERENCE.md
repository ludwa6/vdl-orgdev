## Quick Start Sequence

**Day 1 (2 hours):**
1. Run all "OrgDev Home" prompts (3 prompts)
2. Run all "People & Roles" prompts (4 prompts)
3. Organize sidebar (1 prompt)

**Day 2 (1 hour):**
1. Run all "Governance Structure" prompts (4 prompts)
2. Create Circle Detail template (1 prompt)
3. Test navigation flow

**Day 3 (30 minutes):**
1. Get feedback from 1-2 colleagues
2. Make adjustments
3. Bookmark most-used pages

## Page Structure

### OrgDev Home
- Step 1: Create base structure (headings, columns, placeholders)
- Step 2: Add My Roles view (filtered to current user)
- Step 3: Add Recent Activity (tensions + meetings)

### People & Roles
- Step 1: Create base structure (3 sections)
- Step 2: Add View by Person (Board grouped by person)
- Step 3: Add View by Circle (Board grouped by circle)
- Step 4: Add Vacant Roles table

### Governance Structure
- Step 1: Create base structure
- Step 2: Add Organizational Hierarchy (Board by parent)
- Step 3: Add Domain & Accountabilities (two columns)
- Step 4: Add Policies table

## Bonus
- Circle Detail Template (for individual circle pages)
- Sidebar Navigation (organize all pages/databases)

## Usage Tips

✅ Run prompts in sequence (don't skip steps)
✅ Test each view before proceeding
✅ Be specific when adjusting ("Change the filter to...")
✅ Check on mobile after creating

## Goal

Create a UI that answers:
- "What am I responsible for?" (< 30 seconds)
- "Who does X?" (< 30 seconds)  
- "What roles are vacant?" (immediately visible)
