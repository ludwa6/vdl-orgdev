# Notion UI Design Guide for OrgDev
Vale da Lama - User-Friendly Holacracy Interface

Modeled on HolaFlow's successful UI patterns, prioritizing what colleagues need day-to-day.

## What Made HolaFlow UI Work

1. **Circle-Centric Navigation** - Start with circles, drill down to roles
2. **Role Clarity** - "What am I responsible for?" (My Roles view)
3. **People-First** - "Who does what?" (People → Roles mapping)
4. **Quick Reference** - Core governance elements easily accessible
5. **Minimal Clicks** - Get to needed info in 1-2 clicks maximum

## Recommended 3-Page Structure

### 1. OrgDev Home (Landing/Dashboard)
- My Work (roles I energize)
- Quick Access links
- Recent Activity (tensions, meetings)
- Key Metrics (vacant roles, active tensions)

### 2. People & Roles (Most Used!)
- View by Person (who does what)
- View by Circle (what exists where)
- Vacant Roles (what needs filling)

### 3. Governance Structure (Reference)
- Organizational Hierarchy
- Domain Elements & Accountabilities
- Active Policies

## Key Principles

✅ **Start with People** - Most common question: "What's João responsible for?"
✅ **Minimize navigation depth** - Everything 1-2 clicks away
✅ **Visual grouping** - Use Board views to show relationships
✅ **Status indicators** - Make vacant roles visually obvious
✅ **Mobile-friendly** - Use Board/List views over complex Tables

## Success Metrics

You'll know the UI works when:

✅ People can answer "What am I responsible for?" in <30 seconds
✅ People can answer "Who does X?" in <30 seconds
✅ Vacant roles are immediately visible
✅ People use it daily without asking how
✅ Mobile access works smoothly
